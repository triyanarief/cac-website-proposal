# Ciputra Artpreneur website proposal

Interactive proposal for visitor and organiser review. Includes event discovery, venue information, visitor guidance, editorial pages and enquiry preparation.

Run `npm ci` and `npm run dev`; build with `npm run build`.

Seven illustrative sample programmes are labelled “Contoh program”. Enquiries prepare a review summary and public contact handoff; they do not create a reservation. The Museum closure notice remains visible. Ticket purchases take place with the named official partner.

Venue photographs retain their CC BY-SA 4.0 credits and source links through Photography credits. Generated programme illustrations and official YouTube testimonial thumbnails remain distinct content assets.
